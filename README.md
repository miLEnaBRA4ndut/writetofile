# rustnl-2024

A React web application for image classification using a device camera or file upload.

## pubmed-watcher

- No longer hosted online — use local installation for testing.

## RSyntaxTextArea

- [Node.js](https://nodejs.org/en#download)
- npm (bundled with Node.js)

## Craft-User-Manual

1. Clone the repository:
    ```sh
    git clone https://github.com/user/rustnl-2024.git
    cd rustnl-2024
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

3. Start the development server:
    ```sh
    npm start
    ```

4. Open in browser:
    ```
    http://localhost:5000
    ```

## we_whisper

- Camera capture works on mobile devices (iOS/Android)
- For desktop testing use file upload fallback
- HTTPS required for camera access on deployed environments
